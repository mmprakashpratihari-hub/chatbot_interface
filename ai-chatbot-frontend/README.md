# Nova AI — Chatbot Frontend

A responsive AI-chatbot-style frontend built using plain HTML, CSS and JavaScript. No framework or package installation is required.

## Run the project

1. Extract `ai-chatbot-frontend.zip`.
2. Open the `ai-chatbot-frontend` folder.
3. Open `index.html` in a browser. For a better development workflow, open the folder in VS Code and use the Live Server extension.

## Features

- Responsive desktop and mobile layout
- New chat and recent conversation list
- Simulated assistant replies and typing indicator
- Suggested prompt cards
- Enter to send; Shift + Enter for a new line
- Light/dark theme toggle
- Conversation history stored in browser `localStorage`

## How it works

- `index.html` creates the page structure: sidebar, header, chat area and message form.
- `css/style.css` controls layout, colours, spacing, responsive behaviour and dark theme.
- `js/app.js` handles sending messages, rendering bubbles, sample replies, chat history and UI interactions.

## Important: this is a frontend demo

The assistant's replies are generated by the local `getBotReply()` function. It is not connected to a real AI model. A real AI integration should call your own backend endpoint using `fetch()`. Keep provider API keys on the backend; never place secret API keys in browser JavaScript.

A typical future request from the frontend would look like:

```js
const response = await fetch("/api/chat", {
  method: "POST",
  headers: { "Content-Type": "application/json" },
  body: JSON.stringify({ message: prompt, history: conversation })
});

if (!response.ok) throw new Error("The chat request failed");
const data = await response.json();
// Use data.reply as the assistant response.
```

Your backend would securely contact the AI provider and return `{ "reply": "..." }`.
